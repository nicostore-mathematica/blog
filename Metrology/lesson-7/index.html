回归分析是研究变量之间关系的一种统计方法，而最小二乘法是求解回归模型参数的一种常用数学方法。

Part 1 一元线性回归方程

一元线性回归用于确定两个变量之间的线性关系，本质上是平面上的直线拟合问题。

一元线性回归的目标是寻找一条直线 y^=b0+bx\hat{y} = b_0 + bxy^​=b0​+bx，使之最好地拟合观测数据。

· 离差记号的代数推导

设观测数据具有结构形式 yt=β0+βxt+ϵty_t = \beta_0 + \beta x_t + \epsilon_tyt​=β0​+βxt​+ϵt​ (t=1,2,…,Nt = 1, 2, \dots, Nt=1,2,…,N)，其中 ϵt\epsilon_tϵt​ 为随机误差项。 设求得的经验回归直线方程为：

y^=b0+bx\hat{y} = b_0 + bx y^​=b0​+bx

我们先来规定一些基本概念，如离差与重心。

在统计学中，离差（Deviation）指的是样本观测值与样本均值的差值。直接计算离差会导致计算量偏大，因此通常将其展开简化为便于计算的形式：

(1). 样本中心（重心）：

/Derive/

xˉ=1N∑t=1Nxt,yˉ=1N∑t=1Nyt\bar{x} = \frac{1}{N}\sum_{t=1}^{N} x_t, \quad \bar{y} = \frac{1}{N}\sum_{t=1}^{N} y_t xˉ=N1​t=1∑N​xt​,yˉ​=N1​t=1∑N​yt​

在后续计算中，利用性质 ∑t=1N(xt−xˉ)=0\sum_{t=1}^{N} (x_t - \bar{x}) = 0∑t=1N​(xt​−xˉ)=0 和 ∑t=1N(yt−yˉ)=0\sum_{t=1}^{N} (y_t - \bar{y}) = 0∑t=1N​(yt​−yˉ​)=0 可以大大简化公式推导。

(2). xxx 的离差平方和（Sum of Squares for xxx）：

/Derive/

lxx=∑t=1N(xt−xˉ)2=∑t=1N(xt2−2xtxˉ+xˉ2)=∑t=1Nxt2−2xˉ∑t=1Nxt+Nxˉ2l_{xx} = \sum_{t=1}^{N}(x_t - \bar{x})^2 = \sum_{t=1}^{N}(x_t^2 - 2x_t\bar{x} + \bar{x}^2) = \sum_{t=1}^{N}x_t^2 - 2\bar{x}\sum_{t=1}^{N}x_t + N\bar{x}^2 lxx​=t=1∑N​(xt​−xˉ)2=t=1∑N​(xt2​−2xt​xˉ+xˉ2)=t=1∑N​xt2​−2xˉt=1∑N​xt​+Nxˉ2

由于 ∑xt=Nxˉ\sum x_t = N\bar{x}∑xt​=Nxˉ，带入可得简化公式：

lxx=∑t=1Nxt2−Nxˉ2=∑t=1Nxt2−1N(∑t=1Nxt)2l_{xx} = \sum_{t=1}^{N}x_t^2 - N\bar{x}^2 = \sum_{t=1}^{N}x_t^2 - \frac{1}{N}\left(\sum_{t=1}^{N}x_t\right)^2 lxx​=t=1∑N​xt2​−Nxˉ2=t=1∑N​xt2​−N1​(t=1∑N​xt​)2

(3). x,yx, yx,y 的交叉离差乘积和（Sum of Cross-Products for x,yx, yx,y）：

/Derive/

lxy=∑t=1N(xt−xˉ)(yt−yˉ)=∑t=1N(xtyt−xtyˉ−ytxˉ+xˉyˉ)=∑t=1Nxtyt−yˉ∑t=1Nxt−xˉ∑t=1Nyt+Nxˉyˉ\begin{aligned} l_{xy} &= \sum_{t=1}^{N}(x_t - \bar{x})(y_t - \bar{y}) = \sum_{t=1}^{N}(x_t y_t - x_t \bar{y} - y_t \bar{x} + \bar{x}\bar{y}) \\\\&= \sum_{t=1}^{N}x_t y_t - \bar{y}\sum_{t=1}^{N}x_t - \bar{x}\sum_{t=1}^{N}y_t + N\bar{x}\bar{y} \end{aligned} lxy​​=t=1∑N​(xt​−xˉ)(yt​−yˉ​)=t=1∑N​(xt​yt​−xt​yˉ​−yt​xˉ+xˉyˉ​)=t=1∑N​xt​yt​−yˉ​t=1∑N​xt​−xˉt=1∑N​yt​+Nxˉyˉ​​

代入 ∑xt=Nxˉ\sum x_t = N\bar{x}∑xt​=Nxˉ 和 ∑yt=Nyˉ\sum y_t = N\bar{y}∑yt​=Nyˉ​ 后得到：

lxy=∑t=1Nxtyt−Nxˉyˉ=∑t=1Nxtyt−1N(∑t=1Nxt)(∑t=1Nyt)l_{xy} = \sum_{t=1}^{N}x_t y_t - N\bar{x}\bar{y} = \sum_{t=1}^{N}x_t y_t - \frac{1}{N}\left(\sum_{t=1}^{N}x_t\right)\left(\sum_{t=1}^{N}y_t\right) lxy​=t=1∑N​xt​yt​−Nxˉyˉ​=t=1∑N​xt​yt​−N1​(t=1∑N​xt​)(t=1∑N​yt​)

(4). yyy 的离差平方和：

同理，可推导出：

lyy=∑t=1N(yt−yˉ)2=∑t=1Nyt2−1N(∑t=1Nyt)2l_{yy} = \sum_{t=1}^{N}(y_t - \bar{y})^2 = \sum_{t=1}^{N}y_t^2 - \frac{1}{N}\left(\sum_{t=1}^{N}y_t\right)^2 lyy​=t=1∑N​(yt​−yˉ​)2=t=1∑N​yt2​−N1​(t=1∑N​yt​)2

在求解出回归截距 b0=yˉ−bxˉb_0 = \bar{y} - b\bar{x}b0​=yˉ​−bxˉ 后，将其代入经验回归方程 y^=b0+bx\hat{y} = b_0 + bxy^​=b0​+bx 中：

y^=(yˉ−bxˉ)+bx  ⟹  y^−yˉ=b(x−xˉ)\hat{y} = (\bar{y} - b\bar{x}) + bx \implies \hat{y} - \bar{y} = b(x - \bar{x}) y^​=(yˉ​−bxˉ)+bx⟹y^​−yˉ​=b(x−xˉ)

几何与物理意义：

必定穿过重心： 当输入点为样本均值 x=xˉx = \bar{x}x=xˉ 时，可算得预测值为 y^=yˉ\hat{y} = \bar{y}y^​=yˉ​。这表明：经验回归直线必然严格经过数据观测点的中心几何坐标 (xˉ,yˉ)(\bar{x}, \bar{y})(xˉ,yˉ​)。

残差均值为零： 基于最小二乘法求得的残差 et=yt−y^te_t = y_t - \hat{y}_tet​=yt​−y^​t​，满足 ∑t=1Net=0\sum_{t=1}^{N} e_t = 0∑t=1N​et​=0，即拟合值的平均数始终等于实际观测值的平均数（y^ˉ=yˉ\bar{\hat{y}} = \bar{y}y^​ˉ​=yˉ​）。

根据最小二乘法（Ordinary Least Squares, OLS），我们需要找到一组参数 (b0,b)(b_0, b)(b0​,b)，使得拟合值与真实值之间的残差平方和（Sum of Squared Residuals, SSR）达到最小：

Q(b0,b)=∑t=1Net2=∑t=1N(yt−b0−bxt)2Q(b_0, b) = \sum_{t=1}^{N} e_t^2 = \sum_{t=1}^{N} (y_t - b_0 - b x_t)^2 Q(b0​,b)=t=1∑N​et2​=t=1∑N​(yt​−b0​−bxt​)2

· 代数展开求解回归方程

对目标函数 Q(b0,b)Q(b_0, b)Q(b0​,b) 分别关于未知变量 b0b_0b0​ 和 bbb 求偏导数，并令偏导数等于零：

(1). 对 b0b_0b0​ 求偏导：

/Derive/

∂Q∂b0=−2∑t=1N(yt−b0−bxt)=0  ⟹  ∑t=1Nyt−Nb0−b∑t=1Nxt=0\frac{\partial Q}{\partial b_0} = -2 \sum_{t=1}^{N} (y_t - b_0 - b x_t) = 0 \implies \sum_{t=1}^{N} y_t - N b_0 - b \sum_{t=1}^{N} x_t = 0 ∂b0​∂Q​=−2t=1∑N​(yt​−b0​−bxt​)=0⟹t=1∑N​yt​−Nb0​−bt=1∑N​xt​=0

两边同时除以 NNN：

yˉ−b0−bxˉ=0  ⟹  b0=yˉ−bxˉ\bar{y} - b_0 - b\bar{x} = 0 \implies b_0 = \bar{y} - b\bar{x} yˉ​−b0​−bxˉ=0⟹b0​=yˉ​−bxˉ

(2). 对 bbb 求偏导：

/Derive/

∂Q∂b=−2∑t=1Nxt(yt−b0−bxt)=0  ⟹  ∑t=1Nxtyt−b0∑t=1Nxt−b∑t=1Nxt2=0\frac{\partial Q}{\partial b} = -2 \sum_{t=1}^{N} x_t (y_t - b_0 - b x_t) = 0 \implies \sum_{t=1}^{N} x_t y_t - b_0 \sum_{t=1}^{N} x_t - b \sum_{t=1}^{N} x_t^2 = 0 ∂b∂Q​=−2t=1∑N​xt​(yt​−b0​−bxt​)=0⟹t=1∑N​xt​yt​−b0​t=1∑N​xt​−bt=1∑N​xt2​=0

将 b0=yˉ−bxˉb_0 = \bar{y} - b\bar{x}b0​=yˉ​−bxˉ 带入上式：

∑t=1Nxtyt−(yˉ−bxˉ)∑t=1Nxt−b∑t=1Nxt2=0\sum_{t=1}^{N} x_t y_t - (\bar{y} - b\bar{x})\sum_{t=1}^{N} x_t - b \sum_{t=1}^{N} x_t^2 = 0 t=1∑N​xt​yt​−(yˉ​−bxˉ)t=1∑N​xt​−bt=1∑N​xt2​=0

∑t=1Nxtyt−Nxˉyˉ−b(∑t=1Nxt2−Nxˉ2)=0\sum_{t=1}^{N} x_t y_t - N\bar{x}\bar{y} - b \left(\sum_{t=1}^{N} x_t^2 - N\bar{x}^2\right) = 0 t=1∑N​xt​yt​−Nxˉyˉ​−b(t=1∑N​xt2​−Nxˉ2)=0

· 回归方程的向量空间表达

用矩阵形式表示回归问题时，计算过程更加简洁且利于推广到多元回归。

(1). 构造矩阵模型：

定义观测向量 YYY、设计矩阵 XXX 和参数向量 b\boldsymbol{b}b：

Y=[y1y2⋮yN]N×1,X=[1x11x2⋮⋮1xN]N×2,b=[b0b]2×1Y = \begin{bmatrix} y_1 \\ y_2 \\ \vdots \\ y_N \end{bmatrix}_{N \times 1}, \quad X = \begin{bmatrix} 1 & x_1 \\ 1 & x_2 \\ \vdots & \vdots \\ 1 & x_N \end{bmatrix}_{N \times 2}, \quad \boldsymbol{b} = \begin{bmatrix} b_0 \\ b \end{bmatrix}_{2 \times 1} Y=​y1​y2​⋮yN​​​N×1​,X=​11⋮1​x1​x2​⋮xN​​​N×2​,b=[b0​b​]2×1​

(2). 目标函数与二次型导数：

(3). 解出参数矩阵：

如果 XTXX^T XXTX 可逆，两边左乘 (XTX)−1(X^T X)^{-1}(XTX)−1：

b=[b0b]=(XTX)−1XTY\boldsymbol{b} = \begin{bmatrix} b_0 \\ b \end{bmatrix} = (X^T X)^{-1} X^T Y b=[b0​b​]=(XTX)−1XTY

· 回归方程的稳定性

给定某一个自变量 xxx，根据拟合出的经验公式预测响应值 y^=b0+bx\hat{y} = b_0 + bxy^​=b0​+bx。由于 b0b_0b0​ 和 bbb 均为受样本随机误差影响的估计量，预报值 y^\hat{y}y^​ 也是一个随机变量。

应用随机误差传播律求 y^\hat{y}y^​ 的方差：

σy^2=Var(b0+bx)=σb02+x2σb2+2x Cov(b0,b)\sigma_{\hat{y}}^2 = \text{Var}(b_0 + b x) = \sigma_{b_0}^2 + x^2 \sigma_b^2 + 2 x \, \text{Cov}(b_0, b) σy^​2​=Var(b0​+bx)=σb0​2​+x2σb2​+2xCov(b0​,b)

代入各方差与协方差表达式：

σy^2=(1N+xˉ2lxx)σ2+x2(1lxx)σ2+2x(−xˉlxx)σ2\sigma_{\hat{y}}^2 = \left( \frac{1}{N} + \frac{\bar{x}^2}{l_{xx}} \right) \sigma^2 + x^2 \left( \frac{1}{l_{xx}} \right) \sigma^2 + 2x \left( -\frac{\bar{x}}{l_{xx}} \right) \sigma^2 σy^​2​=(N1​+lxx​xˉ2​)σ2+x2(lxx​1​)σ2+2x(−lxx​xˉ​)σ2

合并配方后即可得到经典的预报方差公式：

σy^2=[1N+(x−xˉ)2lxx]σ2\sigma_{\hat{y}}^2 = \left[ \frac{1}{N} + \frac{(x - \bar{x})^2}{l_{xx}} \right] \sigma^2 σy^​2​=[N1​+lxx​(x−xˉ)2​]σ2

样本量 NNN 越大、且预测点 xxx 越靠近样本均值 xˉ\bar{x}xˉ（即 ∣x−xˉ∣\vert{}x - \bar{x}\vert{}∣x−xˉ∣ 越小）时，预报值 y^\hat{y}y^​ 的标准差越小，精度越高。

当样本量 N→∞N \to \inftyN→∞ 时，σy^2→0\sigma_{\hat{y}}^2 \to 0σy^​2​→0，即在大样本条件下，经验回归直线收敛于理论真实的回归直线。

若我们在收集/设计 xxx 的数据时，让 xxx 保持在更宽的观测范围内（使 lxxl_{xx}lxx​ 极大），就能有效压低分母，使拟合出的斜率 bbb 更准确，进而显著降低整个区间的预报标准差 σy^\sigma_{\hat{y}}σy^​​。

Part 2 方差分析与显著性检验

在一元线性回归分析中，方差分析（ANOVA, Analysis of Variance） 与 显著性检验（F 检验） 是评估线性模型是否有效、自变量 xxx 对因变量 yyy 的解释能力是否具有统计显著性的核心方法。

· 总离差平方和分解

方差分析的核心思想是：将因变量 yyy 的总波动分解为“由自变量 xxx 的线性效应引起的已知波动”与“无法由 xxx 解释的随机误差波动”。

对于任意观测点 yty_tyt​，将其与均值 yˉ\bar{y}yˉ​ 的离差拆分为两部分：

yt−yˉ=(yt−y^t)+(y^t−yˉ)y_t - \bar{y} = (y_t - \hat{y}_t) + (\hat{y}_t - \bar{y}) yt​−yˉ​=(yt​−y^​t​)+(y^​t​−yˉ​)

其中 yt−y^t=ety_t - \hat{y}_t = e_tyt​−y^​t​=et​ 为残差，y^t−yˉ\hat{y}_t - \bar{y}y^​t​−yˉ​ 为拟合值对均值的偏离。

对两边求平方和：

∑t=1N(yt−yˉ)2=∑t=1N[(yt−y^t)+(y^t−yˉ)]2\sum_{t=1}^{N} (y_t - \bar{y})^2 = \sum_{t=1}^{N} \left[ (y_t - \hat{y}_t) + (\hat{y}_t - \bar{y}) \right]^2 t=1∑N​(yt​−yˉ​)2=t=1∑N​[(yt​−y^​t​)+(y^​t​−yˉ​)]2

∑t=1N(yt−yˉ)2=∑t=1N(y^t−yˉ)2+∑t=1N(yt−y^t)2+2∑t=1N(y^t−yˉ)(yt−y^t)\sum_{t=1}^{N} (y_t - \bar{y})^2 = \sum_{t=1}^{N} (\hat{y}_t - \bar{y})^2 + \sum_{t=1}^{N} (y_t - \hat{y}_t)^2 + 2 \sum_{t=1}^{N} (\hat{y}_t - \bar{y})(y_t - \hat{y}_t) t=1∑N​(yt​−yˉ​)2=t=1∑N​(y^​t​−yˉ​)2+t=1∑N​(yt​−y^​t​)2+2t=1∑N​(y^​t​−yˉ​)(yt​−y^​t​)

· 残余方差与残余标准差

代表剔除线性相关性后，实际观测点垂直偏离回归直线的平均幅值（与 yyy 具有相同的物理单位）。

· 显著性检验（FFF 检验法）

进行显著性检验的目的是为了判断自变量 xxx 与因变量 yyy 之间是否存在真正的线性依赖关系，还是仅仅由于随机采样误差产生的“虚假相关”。

在模型 yt=β0+βxt+ϵty_t = \beta_0 + \beta x_t + \epsilon_tyt​=β0​+βxt​+ϵt​ 中：

  • 原假设 H0:β=0H_0: \beta = 0H0​:β=0（xxx 与 yyy 无线性关系，回归方程无显著意义）。
  • 备择假设 H1:β≠0H_1: \beta \neq 0H1​:β=0（xxx 与 yyy 存在显著线性关系）。

Uσ2∼χ2(1)\frac{U}{\sigma^2} \sim \chi^2(1) σ2U​∼χ2(1)

残差均方 MSQ=QN−2MS_Q = \dfrac{Q}{N-2}MSQ​=N−2Q​ 服从自由度为 N−2N-2N−2 的 σ2χ2(N−2)\sigma^2 \chi^2(N-2)σ2χ2(N−2) 分布：

· 重复试验情况

“回归方程显著”仅表明 xxx 的一次项对 yyy 影响显著，但不能排除是否存在非线性趋势或未受控因素。通过在 NNN 个试验点各重复 mmm 次试验，可将残余变差进一步拆分为纯试验误差平方和 QEQ_EQE​ 和失拟平方和 QLQ_LQL​。

先进行平方和与自由度的分解：

总离差平方和 SSS（Total Sum of Squares）被严格地拆解为几个互不干扰的部分：

S=U+QL+QES = U + Q_L + Q_E S=U+QL​+QE​

其平方和为 U=mblxyU = m b l_{xy}U=mblxy​，对应的自由度为 νU=1\nu_U = 1νU​=1。由此计算出的回归方差（均方）为 U/νUU/\nu_UU/νU​。
