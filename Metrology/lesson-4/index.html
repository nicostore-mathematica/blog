Part 1 误差合成

· 函数误差

科学实验和工程测量中，许多量无法直接用仪器测出，当间接测量量 yyy 是多个直接测量量 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​ 的函数 y=f(x1,x2,…,xn)y = f(x_1, x_2, \dots, x_n)y=f(x1​,x2​,…,xn​) 时，由于直接测量量 xix_ixi​ 必然带有误差，这种误差会通过函数关系“传递”给计算结果 yyy。

误差传播公式就是用来定量描述这种传递关系的数学工具。

(1). 系统误差传播公式（全微分形式）：

Δy=∂f∂x1Δx1+∂f∂x2Δx2+⋯+∂f∂xnΔxn\Delta y = \frac{\partial f}{\partial x_1}\Delta x_1 + \frac{\partial f}{\partial x_2}\Delta x_2 + \dots + \frac{\partial f}{\partial x_n}\Delta x_n Δy=∂x1​∂f​Δx1​+∂x2​∂f​Δx2​+⋯+∂xn​∂f​Δxn​

∂f∂xi\displaystyle\frac{\partial f}{\partial x_i}∂xi​∂f​ 的物理意义：称为误差传播系数，直观地反映了直接测量量 xix_ixi​ 对间接测量量 yyy 的影响敏感程度

若 Δxi\Delta x_iΔxi​ 与 Δy\Delta yΔy 量纲相同，起到放大或缩小作用。

若量纲不同，起到单位换算作用。

(2). 随机误差传播公式（一阶泰勒展开）：

δy=∂f∂x1δx1+∂f∂x2δx2+⋯+∂f∂xnδxn\delta y = \frac{\partial f}{\partial x_1}\delta x_1 + \frac{\partial f}{\partial x_2}\delta x_2 + \dots + \frac{\partial f}{\partial x_n}\delta x_n δy=∂x1​∂f​δx1​+∂x2​∂f​δx2​+⋯+∂xn​∂f​δxn​

用 δxi\delta x_iδxi​ 表示随机误差（或某次测量中的随机涨落分量），其理论基础是多元函数的一阶泰勒展开式（Taylor Series Expansion），忽略了二阶及以上的高阶微小量。

· 随机误差的合成

(1). 标准差合成（方和根法）：

当直接测量量 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​ 含有随机误差（其标准差分别为 σ1,σ2,…,σq\sigma_1, \sigma_2, \dots, \sigma_qσ1​,σ2​,…,σq​）时，间接测量量 yyy 的标准差 σ\sigmaσ 如何计算？

一般情况（考虑相关系数 ρij\rho_{ij}ρij​）：

σ=∑i=1q(aiσi)2+2∑1≤i<jqρijaiajσiσj\sigma = \sqrt{\sum_{i=1}^{q}(a_i\sigma_i)^2 + 2\sum_{1\le i<j}^{q}\rho_{ij}a_i a_j\sigma_i\sigma_j} σ=i=1∑q​(ai​σi​)2+21≤i<j∑q​ρij​ai​aj​σi​σj​​

ai=∂f∂xia_i = \displaystyle\frac{\partial f}{\partial x_i}ai​=∂xi​∂f​：误差传播系数（敏感度系数）

ρij\rho_{ij}ρij​（相关系数）：反映变量 xix_ixi​ 和 xjx_jxj​ 之间关联程度的指标，取值范围在 [−1,1][-1, 1][−1,1] 之间。

若 ρij>0\rho_{ij} > 0ρij​>0：说明两变量正相关（一个偏大时另一个也倾向偏大），交叉项会增大总标准差。

若 ρij<0\rho_{ij} < 0ρij​<0：说明负相关，交叉项会相互抵消，从而减小总标准差。

若 ρij=0\rho_{ij} = 0ρij​=0：说明两变量完全独立，交叉项直接消去。

这是概率论中方差的加法定理在多元函数线性化后的具体表现，即

Var(y)=∑ai2Var(xi)+2∑aiajCov(xi,xj)\text{Var}(y) = \sum a_i^2 \text{Var}(x_i) + \text{2}\sum a_i a_j \text{Cov}(x_i, x_j) Var(y)=∑ai2​Var(xi​)+2∑ai​aj​Cov(xi​,xj​)

的展开。

若各分量互不相关（ρij=0\rho_{ij} = 0ρij​=0 且 ai=1a_i = 1ai​=1）：

σ=∑i=1qσi2\sigma = \sqrt{\sum_{i=1}^{q}\sigma_i^2} σ=i=1∑q​σi2​​

这就是最著名的方和根（RSS）公式。当各个直接测量互不影响（ρij=0\rho_{ij}=0ρij​=0）且函数关系为简单的线性加减（ai=1a_i=1ai​=1，例如 y=x1+x2−x3y = x_1 + x_2 - x_3y=x1​+x2​−x3​）时，总标准差等于各分量标准差平方和的平方根。

无论各个单项误差服从什么概率分布（正态分布、均匀分布或三角分布等），只要能够给出各自的标准差（或标准不确定度），就可以通过方和根法则合成总标准差。这是现代测量不确定度评定（GUM法）的基石。

(2). 极限误差合成：

在很多工程领域人们更习惯使用极限误差（Limit Error，通常记为 δ\deltaδ 或 EEE）来限制误差的边界。

极限误差通常对应一定的置信水平（例如在正态分布下，取 3σ3\sigma3σ 对应 99.73%99.73\%99.73% 的置信概率）。 对于某一个分量 xix_ixi​，其极限误差为 δi\delta_iδi​，对应的置信因子（或称覆盖因子）为 kik_iki​。因此，该分量的相当标准差可以表示为：

σi=δiki\sigma_i = \frac{\delta_i}{k_i} σi​=ki​δi​​

同理，最终结果 yyy 的极限误差为 δ\deltaδ，其置信因子为 kkk，对应的标准差为 σ=δk\sigma = \dfrac{\delta}{k}σ=kδ​。

将标准差合成公式中的 σ=δk\sigma = \dfrac{\delta}{k}σ=kδ​ 和 σi=δiki\sigma_i = \dfrac{\delta_i}{k_i}σi​=ki​δi​​ 代入，两边同乘以 kkk 即可得到：

δ=k∑i=1q(aiδiki)2+2∑1≤i<jqρijaiajδikiδjkj\delta = k\sqrt{\sum_{i=1}^{q}\left(\frac{a_i\delta_i}{k_i}\right)^2 + 2\sum_{1\le i<j}^{q}\rho_{ij}a_i a_j \frac{\delta_i}{k_i}\frac{\delta_j}{k_j}} δ=ki=1∑q​(ki​ai​δi​​)2+21≤i<j∑q​ρij​ai​aj​ki​δi​​kj​δj​​​

若各项均服从正态分布且相互独立（ki=kk_i = kki​=k，ρij=0\rho_{ij} = 0ρij​=0， ai=1a_i = 1ai​=1）：

δ=∑i=1qδi2\delta = \sqrt{\sum_{i=1}^{q}\delta_i^2} δ=i=1∑q​δi2​​

当各项均服从正态分布、相互独立，且我们在相同的置信水平下（即置信因子 ki=kk_i = kki​=k 相同）进行评估时，

极限误差的合成形式也表现为简单的方和根。

· 系统误差的合成

系统误差按性质分为两类，合成方法截然不同：

(1). 已定系统误差的合成：

特征：大小和方向均已确切掌握，不具备抵偿性。

合成方法：代数和法

Δ=∑i=1raiΔi\Delta = \sum_{i=1}^{r} a_i \Delta_i Δ=i=1∑r​ai​Δi​

为什么用代数和？ 因为每个已定系统误差 Δi\Delta_iΔi​ 都有确切的正负号。

乘以误差传播系数 ai=∂f∂xia_i = \dfrac{\partial f}{\partial x_i}ai​=∂xi​∂f​ 后，它们在最终结果 yyy 中是相互叠加的。

如果两个误差同向，它们会叠加放大；如果异向，它们会部分抵消。这里必须代入符号进行纯粹的代数加减。

(2). 未定系统误差的合成：

我们知道它存在（例如仪器说明书上写着“精度等级为 ±0.5%\pm 0.5\%±0.5%”），但我们不知道在某一次具体的测量中，它到底是偏大还是偏小、具体数值是多少。我们只知道它被限制在某个区间内（例如不超过 ±e\pm e±e​ 的范围）。

在一组固定的测量条件下，它保持恒定不变（表现出系统误差的特征）。

但是，如果我们改变测量条件（换一台同型号的仪器、换一个操作员、在不同时间测量），或者在综合评价多个来源的此类误差时，它表现出的符号和大小具有不可预测性。

因此，从概率统计和综合作用的角度来看，它们具有类似随机误差的“抵偿性”。

既然它具有随机误差的统计特性，虽然我们不知道它确切在哪一个点，但我们可以把它看作是一个服从某种概率分布（通常假设为均匀分布）随机变量。

当有多个相互独立的未定系统误差时，由于它们方向随机、互不相关，它们的合成不能简单地用代数和（那代表最极端的“悲观估计”，会导致误差范围被严重夸大），而是应该像随机误差一样，采用方和根（RSS）法合成。

合成方法完全可以采用随机误差的合成公式（标准差合成或极限误差合成）。

标准差合成（独立时）：

u=∑i=1s(aiui)2u = \sqrt{\sum_{i=1}^{s}(a_i u_i)^2} u=i=1∑s​(ai​ui​)2​

· 系统误差与随机误差合成

“系统误差（无论已知未知）不随次数增加而减小，而随机误差可以通过多次测量被显著消减。”

在实际测量中，往往需要将已定系统误差、未定系统误差和随机误差综合考虑。

(1). 单次测量情况（设误差传递系数 ai=1a_i = 1ai​=1）：

极限误差合成：

ΔΣ=∑i=1rΔi±∑i=1sei2+∑i=1qδi2\Delta_{\Sigma} = \sum_{i=1}^{r}\Delta_i \pm \sqrt{\sum_{i=1}^{s}e_i^2 + \sum_{i=1}^{q}\delta_i^2} ΔΣ​=i=1∑r​Δi​±i=1∑s​ei2​+i=1∑q​δi2​​

第一部分（∑Δi\sum \Delta_i∑Δi​）：已定系统误差的残余

  • 如果已定系统误差在测量结果中已经通过修正值予以扣除，理论上这部分应该为零或极小。但如果某些已定系统误差没有被完全修正，它们会以代数和的形式直接叠加在总误差的边界上（提供一个整体的系统性偏置方向，即带有 ±\pm± 号的整体平移）。

第二部分（∑ei2+∑δi2\sqrt{\sum e_i^2 + \sum \delta_i^2}∑ei2​+∑δi2​​）：未定系统误差与随机误差的联合方和根

  • eie_iei​：未定系统误差的极限误差（按均匀分布或其他分布折算）。
  • δi\delta_iδi​：随机误差的极限误差。
  • 因为这两者在综合作用时都表现出无规律的“抵偿性”（虽然性质不同，但从统计学合成上看都可以当作随机分量处理），所以它们彼此独立、遵循方和根（RSS）定律融合成一个综合的波动区间。

标准差合成：

σ=∑i=1sui2+∑i=1qσi2\sigma = \sqrt{\sum_{i=1}^{s}u_i^2 + \sum_{i=1}^{q}\sigma_i^2} σ=i=1∑s​ui2​+i=1∑q​σi2​​

这对应现代不确定度评定中的合成标准不确定度：由未定系统误差转换来的标准不确定度分量（B类，uiu_iui​）与随机误差的标准差分量（A类，σi\sigma_iσi​）直接通过方和根进行合成。

(2). nnn 次重复测量情况：

如果在实验中，我们对同一个量进行了 nnn 次重复测量，并取其算术平均值作为最终结果，情况会发生根本性的变化。

系统误差（已定 Δi\Delta_iΔi​ 或未定 eie_iei​）：不具备抵偿性。无论是仪器零点偏移、刻度不准还是环境固定偏差，你在同一个仪器上测 10 次或 100 次，这个偏差依然雷打不动地存在。因此，它们绝不随测量次数 nnn 的增加而减小。

随机误差（δi\delta_iδi​ 或 σi\sigma_iσi​）：具备抵偿性。由于随机误差服从统计规律（正负交替、期望为零），当你进行 nnn 次重复测量并求平均时，正负误差会互相抵消。根据数理统计，均值的方差会缩小为单次测量方差的 1n\dfrac{1}{n}n1​（即标准差缩小为原来的 1n\dfrac{1}{\sqrt{n}}n​1​）。

总极限误差：

ΔΣ=±∑i=1sei2+1n∑i=1qδi2\Delta_{\Sigma} = \pm \sqrt{\sum_{i=1}^{s}e_i^2 + \frac{1}{n}\sum_{i=1}^{q}\delta_i^2} ΔΣ​=±i=1∑s​ei2​+n1​i=1∑q​δi2​​

总标准差：

σ=∑i=1sui2+1n∑i=1qσi2\sigma = \sqrt{\sum_{i=1}^{s}u_i^2 + \frac{1}{n}\sum_{i=1}^{q}\sigma_i^2} σ=i=1∑s​ui2​+n1​i=1∑q​σi2​​

Part 2 误差分配

在设计一台高精度光学仪器、机械传动系统或电子测量装置时，通常客户或指标会规定：“整机允许的最大总误差（或总不确定度）不能超过多少”。此时，设计者的任务就是把这个总指标合理地拆解、分配给各个组成部分或各个直接测量环节。

即给定测量结果允许的总误差（或总不确定度），合理确定各个单项误差的指标。

(1). 等影响原则（等分配原则）：

假设系统中的 nnn 个误差源对总误差造成的贡献是完全均等的。也就是说，不偏袒任何一个环节，让每个环节承担相同比例的误差风险。

根据独立随机变量的方差合成公式（方和根律）：

σy2=∑i=1n(aiσi)2\sigma_y^2 = \sum_{i=1}^{n} (a_i \sigma_i)^2 σy2​=i=1∑n​(ai​σi​)2

如果让每一项对总方差 σy2\sigma_y^2σy2​ 的贡献都完全相等，那么每一项分担的方差就是：

(aiσi)2=σy2n(a_i \sigma_i)^2 = \frac{\sigma_y^2}{n} (ai​σi​)2=nσy2​​

两边开根号后，即可得到各个直接测量量的标准差（或极限误差）分配公式：

δi=δn1aiorσi=σyain\delta_i = \frac{\delta}{\sqrt{n}}\frac{1}{a_i} \quad \text{or} \quad \sigma_i = \frac{\sigma_y}{a_i \sqrt{n}} δi​=n​δ​ai​1​orσi​=ai​n​σy​​

(2). 按可能性调整原则： 平均分配常导致“易实现的过松、难实现的难以达到”。 对难以实现的测量误差项适当扩大，对容易实现的尽量缩小，其余不予调整。

(3). 验算调整后的总误差：合成后若超出允许范围则继续收紧，若过小可适当放宽.

· 微小误差取舍

当某个误差项对总误差的影响很小、可以忽略时，称为微小误差。

若误差有效数字取 1位：当 Dk≤13σyD_k \le \dfrac{1}{3}\sigma_yDk​≤31​σy​（或 0.3σy∼0.4σy0.3\sigma_y \sim 0.4\sigma_y0.3σy​∼0.4σy​）时，可忽略不计。

若误差有效数字取 2位：当 Dk≤110σyD_k \le \dfrac{1}{10}\sigma_yDk​≤101​σy​（或 0.1σy∼0.14σy0.1\sigma_y \sim 0.14\sigma_y0.1σy​∼0.14σy​）时，可忽略。

· 最佳测量方案

在设计间接测量方案时，如何使函数误差 σy\sigma_yσy​ 最小：

(1). 选择最佳函数误差公式：优先选择包含直接测量值数目最少的函数公式。若数目相同，优先选择误差较小的直接测量值所对应的函数公式。

(2). 使误差传播系数尽量小：通过优化几何关系或测量构型，使各个测量值对函数的误差传播系数 ∂f∂xi=0\dfrac{\partial f}{\partial x_i} = 0∂xi​∂f​=0 或趋于最小.
