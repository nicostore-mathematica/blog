Part 1 基本概念

测量不确定度（Measurement Uncertainty）简单来说就是：我们对测量结果可能上下浮动多大范围的一种科学定量评估。

在实际报告中，它通常写成形如 Y=y±UY = y \pm UY=y±U 或 Y=y±ucY = y \pm u_cY=y±uc​（其中 yyy 是估计值，UUU 是扩展不确定度）的形式。这代表着：我们有相当大的把握认为，被测量的真值落在了 y−Uy - Uy−U 到 y+Uy + Uy+U 这个区间之内。

现代测量将不确定度的评定方法清晰地划分为两大类：

A类评定（Class A Evaluation）：过对一系列直接观测数据进行统计学处理来评定标准不确定度。

B类评定（Class B Evaluation）：基于经验、历史数据、环境资料、检定证书所认定的概率分布来评定标准不确定度。

Part 2 标准测量不确定度

· A 类评定

A 类评定是通过对一系列观测数据进行统计分析来评定标准不确定度的方法。它专门用于处理具有随机波动特性的分量。

单次测量值作为估计值：若以单次测得值 xxx 作为被测量的估计值，其标准不确定度直接由样本标准差 s(x)s(x)s(x) 表征，即 u(x)=s(x)u(x) = s(x)u(x)=s(x)。

算术平均值作为估计值：若以 nnn 次测量的算术平均值 xˉ\bar{x}xˉ 作为被测量的估计值，根据数理统计原理，平均值能显著削弱随机误差，因此其标准不确定度会按 n\sqrt{n}n​ 缩小，即 u(xˉ)=s(xˉ)=s(x)nu(\bar{x}) = s(\bar{x}) = \dfrac{s(x)}{\sqrt{n}}u(xˉ)=s(xˉ)=n​s(x)​。

自由度：无论是单次测量还是算术平均值，其 A 类评定的自由度均按贝塞尔公式（Bessel formula）计算为 ν=n−1\nu = n - 1ν=n−1。

笔记

在测量不确定度评定中，每一个标准不确定度分量 uiu_iui​（无论是 A 类还是 B 类）都可以看作是对某个总体标准差 σi\sigma_iσi​ 的估计。 根据数理统计原理：

样本方差或不确定度平方 ui2u_i^2ui2​ 乘以其自由度 νi\nu_iνi​ 再除以真值方差，服从卡方分布（Chi-squared distribution）：

νiui2σi2∼χ2(νi)\frac{\nu_i u_i^2}{\sigma_i^2} \sim \chi^2(\nu_i) σi2​νi​ui2​​∼χ2(νi​)

在卡方分布 χ2(ν)\chi^2(\nu)χ2(ν) 中：

其数学期望（均值）为：E[χ2(ν)]=νE[\chi^2(\nu)] = \nuE[χ2(ν)]=ν

其方差为：Var(χ2(ν))=2ν\text{Var}(\chi^2(\nu)) = 2\nuVar(χ2(ν))=2ν

由此可以反推出单个不确定度平方 ui2u_i^2ui2​ 的期望和方差：

期望：E[ui2]=σi2E[u_i^2] = \sigma_i^2E[ui2​]=σi2​

合成标准不确定度 uc2u_c^2uc2​ 是各个分量平方的和（假设互不相关）：

uc2=∑i=1Nui2u_c^2 = \sum_{i=1}^{N} u_i^2 uc2​=i=1∑N​ui2​

由于 ui2u_i^2ui2​ 各自服从不同自由度 νi\nu_iνi​ 的卡方分布，因此 uc2u_c^2uc2​ 实际上是多个不同自由度的卡方随机变量的线性组合。

这种线性组合的精确概率分布极其复杂（属于非中心或广义卡方加权和），在工程应用和常规查表中根本无法直接使用。

统计学家 Welch 和 Satterthwaite 提出了一种近似替代法——我们能不能假设这个复杂的组合分布，其整体行为近似于某一个单一的卡方分布？

即寻找一个等效的“有效自由度” νeff\nu_{eff}νeff​，使得合成量 uc2u_c^2uc2​ 能够近似地被看作服从自由度为 νeff\nu_{eff}νeff​ 的卡方分布。

为了让一个单一的卡方分布去逼近那个复杂的组合分布，最科学的方法是让它们的数字特征（矩）保持一致。

矩是用来描述概率分布或一组数据特征的数学工具，阶数 kkk 越高，代表对离中心越远的数据细节敏感度越高；这里使用了“前两阶矩匹配”（即均值相等、方差相等）。
