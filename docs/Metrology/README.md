事情的起因来源于两点，一个是飞镖构想的西交方案与深大方案，另一个是我们这学期真的有一门名为“误差理论与数据处理”的课，作为专业课和专业构建的核心，测量理论不可谓不重要，测量数据的置信度和确定度一定程度上也会影响控制系统的输入和反馈......

关于西交和深大方案到底讲了什么，和一些讨论的争议：

> 究其本质是个半开环控制，以末端移动靶为例，末端移动一般是以飞镖发射1600ms之后方才停止移动，而西交使用的则是在飞镖飞行1800ms之后取相机中的三个有效帧，取平均值获得位置/速度信息。然后关闭相机，做一个曲线拟合，使得飞镖落点大概在靶子附近。
>
> 而如果要打随机移动，则可以把时间提前到1400ms，但此时根据我们的测算，镖体大概距离靶子的距离约为13m，此时在测量上会出现一个问题：像素点总量可能只有15~25，摄像头的视差会比较小。但是因为摄像头它的分辨率是有限的，也就是说，离得距离越远的时候，这个半开环的控制的采样误差就越大，那么控制精度就越差了。
>
> 本身openmv相机就容易造成两到三个像素点的误差，那这两到三个像素点放大到在13米观测到那个位置上，能否保证能够通过他有误差之后产生的数据来判断靶子的相对位置到底是左中还是右呢？
>
> 说到这里，究其根本就是测量学的问题了。

原本我打算把这部分放到“计算物理导论”，作为实验物理的一个重要组成部分进行记录，现在我觉得这部分应当独立出来作为一个单独的板块进行学习记录——理由无它，相比之下测量学还是太需要直觉了.
