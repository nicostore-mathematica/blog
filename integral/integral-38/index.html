Part 1 曲线积分

· 第一型曲线积分

对于平面曲线 σ(t)=(x(t),y(t))\sigma(t) = (x(t), y(t))σ(t)=(x(t),y(t))，如果 x(t),y(t)x(t), y(t)x(t),y(t) 是关于 ttt 的连续可微函数，则利用折线逼近曲线的办法，我们定义了 σ\sigmaσ 的长度为

L(σ)=∫αβ[x′(t)]2+[y′(t)]2dt.L(\sigma) = \int_\alpha^\beta \sqrt{[x'(t)]^2 + [y'(t)]^2} dt. L(σ)=∫αβ​[x′(t)]2+[y′(t)]2​dt.

现在考虑一般的情形. 映射 σ:[α,β]→Rn\sigma: [\alpha, \beta] \to \mathbb{R}^nσ:[α,β]→Rn 称为一条参数曲线，我们仍然用折线逼近曲线的办法定义 σ\sigmaσ 的长度.

如果这些折线的长度有上界，即

sup⁡π∑i=1m∥σ(ti)−σ(ti−1)∥<+∞,\sup_\pi \sum_{i=1}^m \|\sigma(t_i) - \sigma(t_{i-1})\| < +\infty, πsup​i=1∑m​∥σ(ti​)−σ(ti−1​)∥<+∞,

L(σ)=sup⁡π∑i=1m∥σ(ti)−σ(ti−1)∥.L(\sigma) = \sup_\pi \sum_{i=1}^m \|\sigma(t_i) - \sigma(t_{i-1})\|. L(σ)=πsup​i=1∑m​∥σ(ti​)−σ(ti−1​)∥.

利用三角不等式我们知道当区间 [α,β][\alpha, \beta][α,β] 的分割加细时，折线的长度单调递增. 如果 σ(t)\sigma(t)σ(t) 的每一个分量均为连续可微函数，则由第七章第一节的推导知 σ\sigmaσ 是可求长的，且长度可以表示为积分

L(σ)=∫αβ∥σ′(t)∥dt.L(\sigma) = \int_\alpha^\beta \|\sigma'(t)\| dt. L(σ)=∫αβ​∥σ′(t)∥dt.

如果曲线不连续，则我们这里给出的曲线长度定义和直观上的长度观念不是一回事.

例如，考虑这样的曲线：当 t=0t = 0t=0 时 (x(0),y(0))=(0,0)(x(0), y(0)) = (0, 0)(x(0),y(0))=(0,0)；当 0<t≤10 < t \leq 10<t≤1 时，(x(t),y(t))=(t,1)(x(t), y(t)) = (t, 1)(x(t),y(t))=(t,1). 按我们的定义，此曲线长度为 222！

从定义可以得到可求长曲线的下列性质：

  • 如果 σ\sigmaσ 为可求长曲线，则对任意 [γ,δ]⊂[α,β][\gamma, \delta] \subset [\alpha, \beta][γ,δ]⊂[α,β]，σ∣[γ,δ]\sigma|_{[\gamma, \delta]}σ∣[γ,δ]​ 也是可求长的；
  • 如果 σ\sigmaσ 为可求长曲线，则对任意 γ∈[α,β]\gamma \in [\alpha, \beta]γ∈[α,β]，有

L(σ)=L(σ∣[α,γ))+L(σ∣[γ,β]).L(\sigma) = L(\sigma|_{[\alpha, \gamma)}) + L(\sigma|_{[\gamma, \beta]}). L(σ)=L(σ∣[α,γ)​)+L(σ∣[γ,β]​).

这是曲线长度的可加性，其证明仍然是利用三角不等式.

为了导出曲线可求长的充分必要条件，我们引入有界变差函数的概念.

定义1（有界变差函数）

⋁αβ(f)=∣f(β)−f(α)∣.\bigvee_\alpha^\beta(f) = |f(\beta) - f(\alpha)|. α⋁β​(f)=∣f(β)−f(α)∣.

  • Lipschitz 函数. 设 ∣f(x)−f(y)∣≤L∣x−y∣|f(x) - f(y)| \leq L|x - y|∣f(x)−f(y)∣≤L∣x−y∣，则

  • 连续可微函数. 根据微分中值定理可知连续可微函数都是 Lipschitz 函数，因而是有界变差函数.

  • 如果 g(x)g(x)g(x) 为 [α,β][\alpha, \beta][α,β] 上的 Riemann 可积函数，则

f(x)=∫αxg(t)dt,x∈[α,β]f(x) = \int_\alpha^x g(t) dt,\quad x \in [\alpha, \beta] f(x)=∫αx​g(t)dt,x∈[α,β]

是 Lipschitz 函数，因此也是有界变差函数.

可以证明，有界变差函数必为两个单调递增函数的差.

定理1（Jordan）

曲线 σ(t)\sigma(t)σ(t) 可求长当且仅当它的每一个分量均为有界变差函数.

/proof/

设 σ(t)=(x1(t),⋯ ,xn(t))\sigma(t) = (x_1(t), \cdots, x_n(t))σ(t)=(x1​(t),⋯,xn​(t)) 可求长，则任给 [α,β][\alpha, \beta][α,β] 的分割 π\piπ，有

这说明 xi(t)x_i(t)xi​(t) 为有界变差函数.

因此 σ(t)\sigma(t)σ(t) 是可求长的.

以下总是假设曲线 σ\sigmaσ 是可求长的. 对 t∈[α,β]t \in [\alpha, \beta]t∈[α,β]，定义

当 σ(t)\sigma(t)σ(t) 为可求长的连续曲线时，s(t)s(t)s(t) 也是连续函数. 当 σ(t)\sigma(t)σ(t) 不在任何区间上取常值时，s(t)s(t)s(t) 是参数 ttt 的连续的严格单调递增函数，从而可逆，其逆记为 t=t(s)t = t(s)t=t(s):

这时，σ(t)=σ(t(s))\sigma(t) = \sigma(t(s))σ(t)=σ(t(s)) 又可以看成关于 sss 的参数曲线，我们将 sss 称为弧长参数.

s′(t)=∥σ′(t)∥或ds=∥σ′(t)∥dt.s'(t) = \|\sigma'(t)\|\quad \text{或}\quad ds = \|\sigma'(t)\| dt. s′(t)=∥σ′(t)∥或ds=∥σ′(t)∥dt.

现在我们考虑可求长曲线上有界函数的积分. 设 fff 是定义在 σ\sigmaσ 上的有界函数，即对任意 σ(t)\sigma(t)σ(t)，f(σ(t))f(\sigma(t))f(σ(t)) 是定义好的实数. 任给 [α,β][\alpha, \beta][α,β] 的分割 π\piπ，取 ξi∈[ti−1,ti]\xi_i \in [t_{i-1}, t_i]ξi​∈[ti−1​,ti​] (1≤i≤m1 \leq i \leq m1≤i≤m)，考虑和

当曲线 σ\sigmaσ 的弧长参数存在时，第一型曲线积分可以转化为通常的 Riemann 积分：

∫σfds=∫0L(σ)f(σ(s))ds;\int_\sigma f ds = \int_0^{L(\sigma)} f(\sigma(s)) ds; ∫σ​fds=∫0L(σ)​f(σ(s))ds;

∫σfds=∫αβf(σ(t))∥σ′(t)∥dt.\int_\sigma f ds = \int_\alpha^\beta f(\sigma(t)) \|\sigma'(t)\| dt. ∫σ​fds=∫αβ​f(σ(t))∥σ′(t)∥dt.

一般地，第一型曲线积分是所谓 Riemann-Stieltjes 积分的一种特殊情形.

· 第二型曲线积分

现在我们考虑这样一个物理问题：设质点在力场 FFF 中沿一条曲线 σ\sigmaσ 运动，求力场 FFF 对该质点所做的功. 我们可以将这个问题转化为曲线上的一个积分问题.

为此，设 σ:[α,β]→Rn\sigma: [\alpha, \beta] \to \mathbb{R}^nσ:[α,β]→Rn 为一条参数曲线，fff 是定义在 σ\sigmaσ 上的取值在 Rn\mathbb{R}^nRn 中的一个向量值函数，其分量记为 fif_ifi​ (1≤i≤n1 \leq i \leq n1≤i≤n). 任取 [α,β][\alpha, \beta][α,β] 的一个分割

π:α=t0<t1<t2<⋯<tm=β,\pi: \alpha = t_0 < t_1 < t_2 < \cdots < t_m = \beta, π:α=t0​<t1​<t2​<⋯<tm​=β,

∑j=1mfi(σ(ξj))(xi(tj)−xi(tj−1)),(ξj∈[tj−1,tj])\sum_{j=1}^m f_i(\sigma(\xi_j))(x_i(t_j) - x_i(t_{j-1})),\quad (\xi_j \in [t_{j-1}, t_j]) j=1∑m​fi​(σ(ξj​))(xi​(tj​)−xi​(tj−1​)),(ξj​∈[tj−1​,tj​])

∫σfidxi=lim⁡∥π∥→0∑j=1mfi(σ(ξj))(xi(tj)−xi(tj−1)).\int_\sigma f_i dx_i = \lim_{\|\pi\| \to 0} \sum_{j=1}^m f_i(\sigma(\xi_j))(x_i(t_j) - x_i(t_{j-1})). ∫σ​fi​dxi​=∥π∥→0lim​j=1∑m​fi​(σ(ξj​))(xi​(tj​)−xi​(tj−1​)).

∫σf1dx1+⋯+fndxn=∫σf1dx1+⋯+∫σfndxn,\int_\sigma f_1 dx_1 + \cdots + f_n dx_n = \int_\sigma f_1 dx_1 + \cdots + \int_\sigma f_n dx_n, ∫σ​f1​dx1​+⋯+fn​dxn​=∫σ​f1​dx1​+⋯+∫σ​fn​dxn​,

这个积分称为形式和 f1dx1+⋯+fndxnf_1 dx_1 + \cdots + f_n dx_nf1​dx1​+⋯+fn​dxn​ 沿 σ\sigmaσ 的第二型曲线积分，在不引起混淆的情形也称为 fff 沿 σ\sigmaσ 的第二型曲线积分.

初看起来第二型曲线积分似乎和第一型曲线积分并无本质不同. 但这两类积分有一个重要的区别，这个区别和曲线的方向有关.

为了说明这一点，我们考虑曲线的重新参数化. 设 ϕ:[γ,δ]→[α,β]\phi: [\gamma, \delta] \to [\alpha, \beta]ϕ:[γ,δ]→[α,β] 为严格单调的可逆连续映射，则复合映射 σ∘ϕ:[γ,δ]→Rn\sigma \circ \phi: [\gamma, \delta] \to \mathbb{R}^nσ∘ϕ:[γ,δ]→Rn 也是一条参数曲线，它和 σ\sigmaσ 的像完全相同，这两条参数曲线只是选取了不同的参数而已.

如果 ϕ\phiϕ 是严格单调递增的，则称这两个参数是同向的；如果 ϕ\phiϕ 是严格单调递减的，则称这两个参数是反向的（不同向）.

不难看出，对于同向的两个参数，第二曲线积分的值不变；而对于反向的两个参数，第二曲线积分的值正好相差一个符号！这和第一型曲线积分是不同的，比如曲线的长度就不依赖于参数的选取.

因此，为了使第二型曲线积分有意义，我们总是要给曲线指定一个方向，这个方向是由某个参数决定的. 给定了方向的曲线称为有向曲线. 如果参数反向，则新的有向曲线记为 −σ-\sigma−σ，这时有

∫−σf1dx1+⋯+fndxn=−∫σf1dx1+⋯+fndxn.\int_{-\sigma} f_1 dx_1 + \cdots + f_n dx_n = -\int_\sigma f_1 dx_1 + \cdots + f_n dx_n. ∫−σ​f1​dx1​+⋯+fn​dxn​=−∫σ​f1​dx1​+⋯+fn​dxn​.

对于可求长曲线来说，第二型曲线积分也是 Riemann-Stieltjes 积分的特殊情况. 对于（分段）连续可微曲线，第二型曲线积分可以转化为 Riemann 积分：

∫σf1dx1+⋯+fndxn=∑i=1n∫αβfi(σ(t))xi′(t)dt.\int_\sigma f_1 dx_1 + \cdots + f_n dx_n = \sum_{i=1}^n \int_\alpha^\beta f_i(\sigma(t)) x_i'(t) dt. ∫σ​f1​dx1​+⋯+fn​dxn​=i=1∑n​∫αβ​fi​(σ(t))xi′​(t)dt.

另一方面，如果 σ\sigmaσ 为连续可微曲线，sss 是其弧长参数，则

∥σ′(s)∥=∥σ′(t)∥⋅(s′(t))−1=1.\|\sigma'(s)\| = \|\sigma'(t)\| \cdot (s'(t))^{-1} = 1. ∥σ′(s)∥=∥σ′(t)∥⋅(s′(t))−1=1.

如果记 σ′(s)=(cos⁡α1,⋯ ,cos⁡αn)\sigma'(s) = (\cos \alpha_1, \cdots, \cos \alpha_n)σ′(s)=(cosα1​,⋯,cosαn​)，则第二型曲线积分可以写为

∫σf1dx1+⋯+fndxn=∫0L(σ)f(σ(s))⋅σ′(s)ds=∑i=1n∫0L(σ)fi(σ(s))cos⁡αids,\int_\sigma f_1 dx_1 + \cdots + f_n dx_n = \int_0^{L(\sigma)} f(\sigma(s)) \cdot \sigma'(s) ds = \sum_{i=1}^n \int_0^{L(\sigma)} f_i(\sigma(s)) \cos \alpha_i ds, ∫σ​f1​dx1​+⋯+fn​dxn​=∫0L(σ)​f(σ(s))⋅σ′(s)ds=i=1∑n​∫0L(σ)​fi​(σ(s))cosαi​ds,

即第二型曲线积分转化成了第一型的曲线积分.

/example/ Riemann 积分作为第二型的曲线积分

设 fff 为 [a,b][a, b][a,b] 上的可积函数，则定积分 ∫abf(x)dx\int_a^b f(x) dx∫ab​f(x)dx 就是 f(x)dxf(x) dxf(x)dx 沿区间 [a,b][a, b][a,b] 的第二型曲线积分，其中区间看成一条曲线，它的方向是参数 xxx 给出的，即 xxx 轴的正向. 我们之所以规定

∫baf(x)dx=−∫abf(x)dx\int_b^a f(x) dx = -\int_a^b f(x) dx ∫ba​f(x)dx=−∫ab​f(x)dx

就是因为 f(x)dxf(x) dxf(x)dx 沿 [a,b][a, b][a,b] 的相反方向的第二型曲线积分要变一个符号.

/example/ 环路积分

如果 σ\sigmaσ 为一条闭曲线（环路），即 σ(α)=σ(β)\sigma(\alpha) = \sigma(\beta)σ(α)=σ(β)，则选定了方向以后，不论从曲线上哪一点出发，沿此闭曲线的第二型曲线积分的值不变，通常我们将这样的积分记为

∮σf1dx1+⋯+fndxn.\oint_\sigma f_1 dx_1 + \cdots + f_n dx_n. ∮σ​f1​dx1​+⋯+fn​dxn​.
